## Featured Projects

### [Simple Bootloader](https://github.com/Nebez-Berzency/simple-bootloader)

A small educational x86 bootloader written in Assembly with NASM. It explores BIOS-based startup, 16-bit Real Mode, and BIOS interrupt `0x10`. The project can be run with QEMU.

### [x86 Assembly Journey](https://github.com/Nebez-Berzency/x86-assembly-journey)

A step-by-step learning repository with small examples for exploring x86 Assembly and low-level concepts, including registers and the BIOS boot process.

### [Rust Journey](https://github.com/Nebez-Berzency/rust-journey)

A work-in-progress repository for learning Rust through language fundamentals, algorithm exercises, data-structure topics, and small project ideas.
